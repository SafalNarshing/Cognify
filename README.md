# Cognify
Enhancement of Mental Conditions Using Cognitive Tools

# Prerequisites
Ensure you have the following tools are in installed on your environment:
- Node.js

Vefiry the configuaration
```
node -v
npm -v
```

# Run locally

1. Clone the repo
   ```
   https://github.com/SafalNarsingh/Cognify
   ```

2. Navigate to the folder
   ```
   cd cognify
   ```

2. Install the dependencies
   ```
   npm install
   ```

4. Begin the app
   ```
   npm run dev
   ```
